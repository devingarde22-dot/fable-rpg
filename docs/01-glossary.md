# Fable — Glossary

**Версия:** 0.1  
**Статус:** CONFIRMED  
**Назначение:** единый словарь для GDD, кода, базы данных, UI и AI-контекста.

## 1. Продуктовые термины

| Термин | Каноническое значение |
|---|---|
| **Fable** | Название игры. Не путать с внутриигровой Лиловой Гарью. |
| **GM** | Ведущий. Единственный человек, который подтверждает последствия, лорные изменения, state-changing AI proposals, награды и rollback. |
| **TV** | Публичная проекция текущего состояния сцены для всей комнаты. |
| **Телефон игрока / Player** | Личная проекция состояния героя и интерфейс игровых карт действий. |
| **Планшет GM** | Полная авторизованная проекция кампании, сцены и инструментов ведущего. |
| **Источник истины** | Авторитетное серверное состояние и подтверждённый журнал событий. Не клиент и не текст AI. |
| **Лиловая Гарь** | Внутриигровой катаклизм/аномальное явление. Не название игры. |
| **Аверенн** | Подтверждённое название королевства. |
| **Вайрмонт** | Столица Аверенна. |
| **Миревальт** | Начальный город и точка старта первого vertical slice. |

## 2. Пространство и структура кампании

| Термин | Каноническое значение |
|---|---|
| **Глобальная карта** | Карта экспедиционных регионов и узлов. Игроки видят всю географическую оболочку, но неизвестные узлы скрывают подробности. GM видит внутренний политический слой. |
| **Узел / Node** | Точка экспедиционного маршрута: город, лагерь, переправа, руины, шахта, заражённая зона или крупное сюжетное место. |
| **Сцена / Scene** | Активное состояние внутри узла: участники, клеточное поле, препятствия, таймеры, видимость и доступные команды. В одном узле может быть несколько сцен. |
| **Экспедиция** | Период от выхода из города/создания маршрута до ручного завершения GM, поражения, отступления или другого terminal outcome. |
| **Маршрут / Edge** | Связь между узлами с условиями, стоимостью, рисками и доступностью. |
| **Checkpoint** | Сохранённая авторитетная версия состояния, к которой GM может вернуться. |
| **Rollback** | Полное восстановление игрового состояния выбранного checkpoint. Для игроков может быть оформлено как сон-кошмар после отдыха в городе. |
| **Scene transfer** | Явный перенос незавершённой сюжетной сцены с закрытого узла на другой узел. |
| **Разведка / Discovery** | Событие, которое превращает неизвестный узел в раскрытый или добавляет слух/описание, но не обязано раскрывать GM-only контент. |

## 3. Режимы героя

| Термин | Каноническое значение |
|---|---|
| **Сражение** | Общий режим сцены: TV показывает сетку, карту, игроков и мобов. |
| **Бой** | Персональное состояние героя, в котором на телефоне доступны игровые карты действий и защитный слот. |
| **Перемещение** | Персональное состояние без обычных атакующих карт. На телефоне отображаются четыре стрелки; каждое нажатие перемещает героя на одну клетку. Защитный слот может оставаться доступным для аварийной защиты. |
| **Ближний бой** | Состояние контакта с врагом. Диагональная соседняя клетка считается ближней. |
| **Дальний бой** | Состояние, в котором герой может получить и применять допустимые дальние карты. |
| **Режим карты** | Фильтр одной общей колоды, а не новая колода. Определяет, какие карты доступны сейчас. |
| **Клетка** | Одна позиция сетки. Одна клетка равна одному метру. Перемещение только ортогональное. |
| **Линия видимости / LoS** | Проверка, можно ли провести действие от источника к цели с учётом стен и препятствий. |
| **Укрытие** | Баррикада/статуя, через которую врага видно, но атаковать через неё нельзя. Стена полностью блокирует линию выстрела. |

## 4. Карты и колода

| Термин | Каноническое значение |
|---|---|
| **Игровая карта действия** | Карта способности, атаки, предмета, поддержки или защиты на телефоне. Не является картой местности. |
| **Общая колода героя** | Персональная колода одного героя, сформированная экипировкой, навыками, статусами, предысторией и прогрессией. |
| **Обычная рука** | До 5 игровых карт действий. |
| **Слот защиты** | Отдельный слот с одной картой защиты, не занимающий место в пяти обычных картах. |
| **Сброс / Discard** | Место, куда уходят сыгранные и вытесненные карты. Карта не исчезает бесследно. |
| **Дальняя карта** | Карта с дальним режимом применения и допустимой дальностью/LoS. |
| **Ближняя карта** | Карта для цели в соседней клетке. |
| **Универсальная карта** | Карта, разрешённая в нескольких режимах. |
| **Фильтр карты** | Проверка режима, дистанции, навыка, экипировки, статусов, стоимости и условий карты. |

## 5. Бой и враги

| Термин | Каноническое значение |
|---|---|
| **Враг / Enemy** | Серверная сущность с HP, защитой, позицией, пулом намерений и правилами выбора цели. У врага нет игровой колоды. |
| **Намерение / Intent** | Телеграфируемое действие врага с иконкой, таймером, условиями и результатом. |
| **Intent timer** | Серверный обратный отсчёт до разрешения намерения; на TV отображается кольцом вокруг иконки. |
| **Базовое намерение движения** | Сближает врага с ближайшим доступным игроком. До контакта ближе 5 клеток — одно намерение; дальше — до двух. |
| **Fallback** | Следующее допустимое намерение, если текущее стало невозможным. |
| **Сбивание намерения** | Отмена текущего намерения из-за контакта, стены, потери цели, статуса или другой проверки. |
| **Отступление** | Переход игрока из ближнего боя в режим перемещения. Каждый окружающий враг получает бесплатную базовую атаку с групповым снижением урона. |
| **Групповой коэффициент отступления** | Для атакующих при отступлении: первый враг 100%, второй 50%, последующие слабее по формуле. В обычном бою не применяется. |
| **Тяжёлое ранение** | Состояние игрока до конца сражения, в котором он ничего не может делать; после сражения восстанавливается с 1 HP по правилам кампании. |

## 6. Состояние, статусы и ресурсы

| Термин | Каноническое значение |
|---|---|
| **HP** | Здоровье. Базовый масштаб игрока около 1000 HP. |
| **Стамина** | Ресурс игровых карт. Базово 3, восстанавливается со временем; перемещение стамину не тратит. |
| **Максимальная стамина** | Верхний предел ресурса из экипировки, навыков и статусов. |
| **Статус** | Временный или постоянный модификатор параметров, ресурсов или правил взаимодействия. |
| **Состояние / Entity state** | Особое положение, ограничивающее доступные действия: обездвижен, тяжело ранен, без сознания и т.п. Имеет приоритет над обычными картами. |
| **Слой статуса / Status layer** | Отдельное наложение эффекта с источником, силой, таймером и правилами снятия. |
| **Обездвиживание** | Состояние/контроль, запрещающий перемещение на время. В vertical slice базово 15 секунд. |
| **Охрана союзника** | Бафф, дающий базово +20% защиты на 15 секунд. |

## 7. События и технические термины

| Термин | Каноническое значение |
|---|---|
| **Command** | Запрос клиента на действие. Сам по себе не меняет состояние. |
| **Event** | Подтверждённый сервером факт изменения состояния. |
| **Projection** | Фильтрованное представление server state для конкретной роли/устройства. |
| **sceneRevision** | Версия состояния сцены для защиты от stale commands. |
| **requestId** | Идемпотентный идентификатор команды клиента. |
| **serverReceiveSequence** | Стабильный порядок получения команд сервером. |
| **Simulation tick** | Серверный шаг симуляции; baseline 20 Hz. |
| **Input window** | Окно почти одновременных действий; baseline 250 мс. |
| **Seed** | Воспроизводимое значение для случайных целей, tie-break и replay. |
| **Golden test** | Тест с заранее утверждённым результатом, который защищает правило от незаметного изменения. |
| **Context packet** | Ограниченный набор документов и файлов, который AI получает для конкретной задачи. |
| **Rule ID** | Стабильный идентификатор правила, на который ссылаются код, тест и Decision Record. |
